# Meu Dia IA v0.11.5 — ZSky.ai + CapCut guiado

## O que mudou

O fluxo universal de vídeo agora possui cinco formas de produção:

1. IA cria o vídeo.
2. Minhas gravações → IA externa edita.
3. Minhas gravações + IA.
4. ZSky.ai cria os takes → edição manual no CapCut.
5. Eu gravo → edição manual no CapCut.

### ZSky.ai → CapCut

O sistema gera, cena por cena:
- prompt visual para o campo principal do ZSky.ai;
- prompt de som/música para o campo de áudio;
- orientação sobre quando subir imagem real de referência para preservar Denize, Greg ou produto;
- duração e objetivo de cada take;
- instrução para baixar e nomear os takes na ordem correta.

Depois, o próprio sistema fornece um roteiro operacional de CapCut com:
- criação do projeto 9:16;
- importação e ordem da timeline;
- duração/corte de cada cena;
- transição indicada entre os takes;
- movimento obrigatório quando houver foto;
- texto, logo, cores e identidade corretas por projeto;
- orientação de áudio, legendas e música;
- exportação do master final.

### Eu gravo → CapCut

O Diretor de Gravação continua dizendo exatamente o que filmar. Depois da gravação, o sistema mostra o mesmo passo a passo de edição no CapCut, adaptado ao projeto, ao conteúdo, ao CTA e aos canais planejados.

### Retorno do CapCut

Nos dois novos modos não é necessário exportar ZIP para IA externa.
Após editar, o usuário importa o MP4 final diretamente no fluxo de vídeo. O sistema:
- pede conferência de formato, cortes/transições, texto, marca, áudio e CTA;
- cria o conteúdo para todos os canais já planejados;
- adapta CTA e hashtags por plataforma;
- mantém recomendação de música por canal para a hora da postagem;
- envia o resultado para a mesma tela de validação/publicação já usada pelo restante do sistema.

## Inteligência por projeto

A orientação muda automaticamente para:
- Corrida de Carreira;
- Funcional UP;
- Greg;
- TikTok Shop.

Logo, paleta, estética, ritmo, transições, tratamento de pessoas/produto, áudio e CTA seguem o contexto correto da tarefa.
